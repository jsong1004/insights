# Cloud Build Quick Reference

## Initial Setup

```bash
# Run automated setup
./setup-gcp-cloudbuild.sh

# Or specify project
./setup-gcp-cloudbuild.sh my-project-id
```

## Deployment Commands

```bash
# Production deployment
gcloud builds submit --config cloudbuild.yaml

# Development deployment
gcloud builds submit --config cloudbuild-dev.yaml

# Custom configuration
gcloud builds submit \
  --config cloudbuild.yaml \
  --substitutions=_SERVICE_NAME=my-service,_MEMORY=8Gi,_MAX_INSTANCES=20
```

## Secret Management

```bash
# Update secrets
echo 'sk-...' | gcloud secrets versions add OPENAI_API_KEY --data-file=-
echo 'tvly-...' | gcloud secrets versions add TAVILY_API_KEY --data-file=-
echo 'AIza...' | gcloud secrets versions add FIREBASE_WEB_API_KEY --data-file=-

# List secrets
gcloud secrets list

# View secret value (requires permission)
gcloud secrets versions access latest --secret=OPENAI_API_KEY
```

## Monitoring

```bash
# List recent builds
gcloud builds list --limit=10

# View build logs
gcloud builds log BUILD_ID

# Stream build logs
gcloud builds log BUILD_ID --stream

# View service logs
gcloud logging read 'resource.type="cloud_run_revision"' --limit=50

# Get service URL
gcloud run services describe ai-insights-generator \
  --region=us-west1 \
  --format="value(status.url)"
```

## Testing

```bash
# Test health endpoint
SERVICE_URL=$(gcloud run services describe ai-insights-generator \
  --region=us-west1 \
  --format="value(status.url)")
curl $SERVICE_URL/status

# Test full application
open $SERVICE_URL
```

## Automated Triggers

```bash
# GitHub trigger
gcloud builds triggers create github \
  --repo-name=YOUR_REPO \
  --repo-owner=YOUR_ORG \
  --branch-pattern='^main$' \
  --build-config=cloudbuild.yaml

# List triggers
gcloud builds triggers list

# Run trigger manually
gcloud builds triggers run TRIGGER_NAME --branch=main
```

## Troubleshooting

```bash
# Check service status
gcloud run services describe ai-insights-generator --region=us-west1

# View service environment variables
gcloud run services describe ai-insights-generator \
  --region=us-west1 \
  --format="value(spec.template.spec.containers[0].env)"

# Check IAM permissions
gcloud projects get-iam-policy PROJECT_ID \
  --flatten="bindings[].members" \
  --filter="bindings.members:serviceAccount:ai-insights-service@*"

# Verify Artifact Registry
gcloud artifacts repositories list --location=us-west1
gcloud artifacts docker images list us-west1-docker.pkg.dev/PROJECT_ID/cloud-run-source-deploy
```

## Cleanup

```bash
# Delete Cloud Run service
gcloud run services delete ai-insights-generator --region=us-west1

# Delete development service
gcloud run services delete ai-insights-generator-dev --region=us-west1

# Delete Docker images
gcloud artifacts docker images delete \
  us-west1-docker.pkg.dev/PROJECT_ID/cloud-run-source-deploy/ai-insights-generator:latest

# Delete secrets (careful!)
gcloud secrets delete OPENAI_API_KEY
```
